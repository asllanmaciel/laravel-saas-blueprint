# Security Policy

## Reporting a vulnerability

If you discover a security issue in this repository or in one of the architectural recommendations documented here, please avoid opening a public issue with exploit details.

Instead, report the problem privately through GitHub's security reporting features when available, or contact the maintainer through the channels listed on the GitHub profile.

Please include:

- the affected document, example, or recommendation;
- a clear description of the risk;
- reproduction steps or a proof of concept when applicable;
- suggested mitigation, if known.

## Scope

This repository is an architectural blueprint and reference project. It does not operate a hosted production service and does not contain credentials, customer data, or production infrastructure.

Security reports are still welcome when documentation or examples could encourage unsafe implementation patterns.

## Disclosure

Please allow reasonable time for review and correction before publicly disclosing a reported vulnerability.
